# Cricket chirp recognition: publication data and notebooks

Code and experimental data for *A shared circuit architecture for multiscale signal recognition in crickets*.

## Folders

- `data/` — experimental inputs: behavioral tables, species response summaries, song files in `data/song/`, and phylogeny.
- `saved_results/` — supplied numerical results that take a long time to regenerate. The notebooks read these files and never write to this folder. `fits_best_available.npz` contains the final parameters for all 14 species.
- `results/` — newly computed numerical results. This folder starts empty and is ignored by Git.
- `figures/` — PDFs generated by the figure notebooks; ignored by Git.
- `src/` — Python model, data, and plotting code imported by the notebooks.
- `notebooks/` — figure notebooks, the species fitting notebook, the two parameter sweep notebooks, and `ncb.mplstyle`.

## Run locally

Use Python 3.14. From this folder:

```sh
uv venv --python 3.14 .venv
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python -m jupyterlab notebooks/
```

Run a figure notebook from top to bottom. Figures 3, 4, S2, and S3 read supplied caches by default; set `RUN_EXPENSIVE = True` to regenerate a cache in `results/`. Figure 5 reads the supplied parameter sweeps and final species fits. To recompute those, run `sweep_adaptation.ipynb`, `sweep_inhibition.ipynb`, or `FitSpecies.ipynb`. The latter runs its optimizers only when `RUN_FITS = True`.

The saved final fit archive contains historical Nelder–Mead selections for RUB and VOC. Their exact parameters are preserved. The fitting notebook reruns COBYQA and Powell only, so a new fit archive in `results/` may differ. Some saved NumPy archives contain Python objects; load them only from a trusted copy of this folder.
